The [data](./data) folder contains the raw data files.

The [DataCleaning_CVRP.ipynb](./DataCleaning_CVRP.ipynb) contains the code for data cleaning and the CVRP.

The [SLO_Clustering.ipynb](./SLO_Clustering.ipynb] contains the code for the allocation of customers.

The folders [old_allocation](./old_allocation) and [new_allocation](./new_allocation) contain the distance and time matrices between the relevant centers and their client before and after the allocation.
